# Trustindex alternatives

A short, maintained list of alternatives to [Trustindex](https://www.trustindex.io/) for showing Google reviews on a website, with a focus on WordPress and SEO.

> Disclosure: this list is maintained by the team behind Revys, which is our product. We try to keep the comparison fair. Pull requests with corrections are welcome.

## Why look for a Trustindex alternative?

Most review widgets load reviews with JavaScript or inside an iframe. That works for visitors, but search engines often can't read that content, so your reviews don't help your pages rank. Common reasons people switch:

- Reviews rendered by JavaScript aren't reliably crawlable.
- Extra scripts can slow down the page.
- Some features are only available on paid plans.

## How to choose

1. Do you need the reviews to be indexed by Google? Prefer server-rendered HTML.
2. How much page weight can you accept? Fewer external scripts load faster.
3. Do you only need Google reviews, or several platforms?
